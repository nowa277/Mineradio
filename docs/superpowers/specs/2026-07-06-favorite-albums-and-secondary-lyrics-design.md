# 收藏专辑与副文本缩放设计

## 边界

- 将“翻译大小”和“罗马音大小”合并为“翻译/罗马音大小”，只影响当前歌词下方的翻译或罗马音；保留“副歌词大小”对多行队列非当前歌词的独立控制。
- 兼容已有本地配置：优先读取新字段；旧配置按当前启用的翻译/罗马音选取对应旧值迁移。
- 收藏专辑仅使用网易云登录态，不与 QQ 歌单、播客或本地音乐混合。

## 数据与交互

- 后端提供收藏专辑分页列表和专辑曲目接口，Cookie 仅留在服务端。
- 左侧增加“收藏专辑”标签页；专辑卡片显示封面、名称、歌手和歌曲数，点击后载入专辑曲目并从首曲播放。
- Home 右下卡片改为“收藏专辑”，显示第一张收藏专辑并打开左侧对应标签页。

## 性能

- 收藏专辑列表按需加载并缓存，刷新时才重新请求。
- 歌词滑条仅在值变化时重建当前歌词纹理，不增加逐帧对象创建。
